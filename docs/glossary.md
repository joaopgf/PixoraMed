# Glossário PT → EN

Uma tradução por termo, usada em todo o código (backend, frontend, ai-service e infra). Textos que aparecem para o usuário continuam em português.

| Português | Inglês no código |
|---|---|
| usuário | user |
| cadastro / cadastrar | register |
| entrar / login | login |
| sair | logout |
| senha | password |
| sessão | session |
| treino | training |
| resultados dos treinos | training results |
| previsão / análise | prediction (registro) · analysis (fluxo na tela) |
| histórico | history |
| modelo | model |
| módulo | module |
| tipo de câncer | cancer type (`skin`, `oral`, `brain`) |
| Pele / Oral / Cérebro | skin / oral / brain |
