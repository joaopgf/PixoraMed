# frontend (React + Vite)

Site do PixoraMed em React 19 (JavaScript). Detalhes de uso em `README.md`.

Antes de mexer no código, leia as skills desta pasta:

- `.claude/skills/frontend-architecture`: pastas, fluxo de dados, rotas, login, ligação com o backend e acessibilidade.
- `.claude/skills/frontend-best-practices`: estado no lugar certo, componentes x páginas, sem regra de negócio nem segredo no navegador.

Regras rápidas: código e nomes em inglês, textos da tela em português; fontes só pelas variáveis `--font-size-*`; a API é chamada só por `src/api`.

Validar: `npm run build`.
